# Sepehr Elementor Widgets

## English

Sepehr Elementor Widgets is a modular Elementor addon built with PHP OOP
architecture.

## Features

-   Custom Elementor widgets
-   Modular architecture
-   Secure AJAX handling
-   Conditional asset loading
-   Translation ready

## Widgets

### Dynamic Post Grid Pro

- AJAX category filter
- AJAX load more
- Advanced post query controls

![Dynamic Post Grid Pro](screenshots/dynamic-post-grid-pro.png)

### Pricing Table Pro

Professional pricing table widget.

### Testimonial Carousel

Responsive testimonial slider.

### Image Card

Modern image card widget.

![Image Card](screenshots/image-card.png)

## Installation

Copy the plugin into:

wp-content/plugins/

Activate it from WordPress dashboard.
